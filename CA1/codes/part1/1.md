
# Part 1: Inter-Process Communication (IPC) via Named Pipes

---


### 1. Correct Execution Order
To ensure the Named Pipes (FIFOs) are created and ready to receive data, the **Worker** must be started before the **Interface**. If the Interface is started first, it will fail to connect because the pipes do not exist yet.

1. **First:** Start the `worker.go` in one terminal.
2. **Second:** Start the `interface.go` in a separate terminal.

### 2. How to run the Worker
Open a terminal, navigate to the `part1` directory, and run the following command. The Worker will create the named pipes (e.g., `/tmp/req_pipe` and `/tmp/res_pipe`), start listening for incoming requests, and log the operations.
```bash
go run worker.go

```

*(Leave this terminal open and running in the background).*

### 3. How to run the Interface

Open a second terminal, navigate to the `part1` directory, and run the client interface. This will provide an interactive command-line prompt where you can type your mathematical operations.

```bash
go run interface.go

```

### 4. Message Exchange Protocol

The communication between the Interface and the Worker is built on top of **Linux Named Pipes (FIFOs)** and structured using **JSON**.

1. **Serialization (Interface):** The user inputs a command (e.g., `ADD 5 7`). The Interface parses this and converts it into a JSON `Request` struct (`{"operation":"ADD", "a":5, "b":7}`).
2. **Transmission:** The JSON payload is written to the Request Pipe (`/tmp/req_pipe`).
3. **Processing (Worker):** The Worker reads the JSON from the Request Pipe, deserializes it, performs the requested mathematical operation, and creates a JSON `Response` struct.
4. **Reception (Interface):** The Worker writes the JSON response (`{"result":12, "error":""}`) to the Response Pipe (`/tmp/res_pipe`). The Interface reads this, deserializes it, and displays the final result to the user.

### 5. Sample Inputs and Outputs

**Standard Operations:**

* Input: `ADD 15 5` ➔ Output: `Result: 20`
* Input: `SUB 10 3.5` ➔ Output: `Result: 6.5`
* Input: `MUL -4 5` ➔ Output: `Result: -20`

**Bonus Operations:**

* Input: `MOD 10 3` ➔ Output: `Result: 1`
* Input: `POW 2 8` ➔ Output: `Result: 256`
* Input: `MAX 10 20` ➔ Output: `Result: 20`

**Error Handling:**

* Input: `DIV 10 0` ➔ Output: `Error: division by zero`
* Input: `ADD 5` ➔ Output: `Invalid input format. Use: OP A B`
* Input: `XOR 1 1` ➔ Output: `Error: unknown operation`
